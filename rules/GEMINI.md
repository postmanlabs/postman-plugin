You have the Postman plugin installed and available. Postman keeps API contracts/collections, environments and mocks as files beside the code, reviewable in Git and runnable in CI. The plugin's skills cover designing and reviewing HTTP endpoints and spotting breaking changes; finding an API, its owner and the services that consume it, beyond this repository too; mocking APIs that aren't built or reachable and running code against simulated dependencies, failures included; sending and testing requests, load tests, scheduled monitors and CI lint, governance and AI-readiness gates; capturing and replaying webhooks; using environments and secrets in API calls without exposing them to agents. `api-engineer` is the default entry point for this plugin; use it when it isn't clear which skill fits best.
